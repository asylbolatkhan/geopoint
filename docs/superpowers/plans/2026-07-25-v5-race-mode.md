# GeoVictorina V5: онлайн батл — жарыс режимі + UI түзетулер + жеке кездесулер

## Контекст

Қолданушы онлайн батлды сынап көріп, 5 түзету сұрады:
1. **Күтуді алып тастау** — lockstep орнына әркім өз қарқынымен жарысады; жылдамдық шешуші (тең ұпайда жылдамырақ аяқтаған жеңеді — resolveBattle-дың қолданыстағы ережесі).
2. **Сұрақ реті ойыншыға бөлек** — база бір, беру реті әртүрлі (сайттағыдай/асинхронды батлдағыдай). `renderForPlayer` онсыз да per-player ретпен қайтарады — lockstep оны ортақ ретпен қайта жазған еді; енді әр ойыншының өз тізбегі қолданылады.
3. **«Дұрыс/Қате» жазуын алып тастау** — QuizPlay-дегі мәтіндік фидбэк жолы өшеді (80-84 жолдар), рамка түсі + haptic қалады. i18n-нан feedbackCorrect/feedbackWrong өшеді (екі тілден).
4. **Тулар рамка ортасында** — QuizPlay және OnlineRound-тағы flag-нұсқа батырмаларына `flex items-center justify-center`.
5. **Жеке кездесулер (h2h)** — «3–1–2» (жеңіс–тең–жеңіліс) статистикасы: батл БАПТАУ экранында + НӘТИЖЕ экрандарында (асинхронды finished + онлайн end) — қолданушы растаған.

**Қолданушы растаған ережелер:** аяқтап қойған ойыншы күту кезінде байланыстан шықса — ЖЕҢІЛМЕЙДІ (нәтижесі сақталады, қарсылас аяқтағанда матч әділ шешіледі); h2h — баптау + нәтиже экрандарында.

## Жаңа модель (RACE)

Ортақ 3с countdown → әр ойыншы ӨЗ тізбегімен (renderForPlayer реті) өз қарқынымен жүреді. Әр сұраққа серверлік 15с дедлайн; жауап/timeout → жеке нәтиже (тек түстер, FEEDBACK_MS 900мс, серверлік next-таймер) → келесі сұрақ. Бірінші аяқтаған «күту» экранында қарсыластың тірі прогресін көреді. Екеуі де аяқтағанда resolveBattle (correct desc → durationMs asc). Ұпай/persist/күндік лимит/leave-forfeit өзгеріссіз.

## Протокол өзгерістері

**Жаңа S→C:** `q:start {matchId, idx, total, question, deadline, serverNow}` · `q:result {matchId, idx, correctOption, yourAnswer, yourCorrect, scores, nextAt, serverNow}` · `opponent:progress {answered, score, finished}` · `match:waiting {matchId, opponentProgress, opponentDisconnected, serverNow}`.
**Өшеді:** round:start / round:result / round:opponent_answered.
**Өзгереді:** `match:opponent_reconnected {serverNow}` — deadline өрісі ЖОҚ (қарсыластың таймеріне тимейді); `match:snapshot` racing-пішінге көшеді (idx, sub, question?, deadline?, feedback?, opponentProgress, opponentDisconnected; matchId/total МІНДЕТТІ — клиент тәуелді).
**C→S:** `round:answer` → `q:answer {matchId, idx, optionIndex}` (таза rename, alias жоқ — сервер рестарты барлық матчты онсыз да жояды, ескі клиент матч ортасында жаңа серверге қарсы тұра алмайды).
**Өзгеріссіз:** match:start/match:end/match:none/opponent_disconnected/invite*/presence/error.

## Task 1 — Сервер: движок RACE + handler routing + толық тест қайта жазу

**Файлдар:** `server/src/online/matchEngine.js` (өзек қайта жазылады), `server/src/online/handler.js` (тек routing), `server/tests/matchEngine.test.js` (толық қайта жазу).

Константалар: COUNTDOWN_MS 3000, ANSWER_GRACE_MS 1500, DISCONNECT_GRACE_MS 20000 қалады; REVEAL_MS өшеді; `export const FEEDBACK_MS = 900` қосылады.

**State:** phase `countdown|racing|finished|aborted`; countdownEndsAt; per-player: `seq` (renderForPlayer массиві — өз реті), `correct` (canonical-indexed), `idx`, `sub` ('question'|'feedback'|'done'), `qStartAt/qDeadline` (sub=question), `nextAt` (sub=feedback), `lastResult` ({correctOption, yourAnswer, yourCorrect} — snapshot үшін), `frozen` (null | {kind:'q'|'next', remainingMs}), `score, durationMs, finishedAt, connected, graceDeadline`. Ортақ order/matchSeed/paused ӨШЕДІ. createMatch-тан matchSeed параметрі алынады.

**Таймерлер:** `countdownEnd` (ортақ), `q:<id>` (дедлайн+grace), `next:<id>` (фидбэк соңы), `grace:<id>`.

**Өтулер:**
- countdownEnd → racing; әр connected ойыншыға startQuestion(0) (q:start + q:<id> таймер); өшік ойыншы → idx 0, sub question, frozen {kind:'q', remainingMs:ROUND_MS}.
- applyAnswer(id, idx, opt): қорғандар — phase racing, p.connected (өшік ойыншыдан жауап еленбейді), sub==='question', idx===p.idx, valid opt, now ≤ qDeadline+grace. **atMs = min(ROUND_MS, now − qStartAt)** (жылдамдық — тай-брейк, сондықтан кэп міндетті). completeQuestion: ok=opt===p.correct[p.seq[idx].index]; score/durationMs; lastResult; sub='feedback', nextAt=now+900. Effects: clearTimer q:<id>, q:result өзіне, opponent:progress (қарсылас connected болса), setTimer next:<id>.
- q:<id> таймері (timeout): сол жол, opt=null, atMs=ROUND_MS.
- next:<id>: idx+1 < total → startQuestion(idx+1); әйтпесе sub='done', finishedAt; егер қарсылас та done → finishMatch (persist → match:end×2 → end; end БАРЛЫҚ таймерді, соның ішінде кез келген grace-ті тазалайды); әйтпесе өзіне match:waiting {opponentProgress, opponentDisconnected}, қарсыласқа opponent:progress {answered: total, finished: true}.
- applyDisconnect: connected=false; екеуі де өшік → aborted (persist ЖОҚ). Sub бойынша: 'question' → frozen {kind:'q', remainingMs}, clearTimer q:<id>; 'feedback' → frozen {kind:'next', remainingMs}, clearTimer next:<id>; **'done' → freeze ЖОҚ, grace таймері ҚОЙЫЛМАЙДЫ** (аяқтаған ойыншы жазаланбайды — қолданушы шешімі); countdown кезінде → freeze жоқ (countdownEnd өзі өшік ойыншыны frozen q0 етеді). done емес болса setTimer grace:<id>. Қарсыласқа match:opponent_disconnected (АҚПАРАТТЫҚ — оның таймерлері жүре береді).
- applyReconnect: clearTimer grace; frozen болса: kind q → qDeadline=now+remaining, qStartAt=qDeadline−ROUND_MS (atMs әділдігі), q:<id> қайта; kind next → nextAt=now+remaining, next:<id> қайта; snapshot өзіне; қарсыласқа match:opponent_reconnected {serverNow} (deadline ЖОҚ).
- grace:<id> → forfeit (өшік ойыншы жеңіледі — тек 'done' ЕМЕС ойыншыларға қойылады, сондықтан аяқтағандар қауіпсіз). applyLeave → forfeit (кез келген sub-та, done-да да — саналы шығу).
- Аяқтаған ойыншы racing қарсыласы өшкенде: қарсыластың grace-і бітсе → forfeit, аяқтаған жеңеді; қарсылас та done болып ол өшік болса → finishMatch әділ нәтиже (end grace-терді тазалайды).

**snapshotFor:** base {matchId, total, phase, scores, opponent, serverNow}; countdown → countdownEndsAt; racing → idx, sub, opponentProgress {answered, score, finished}, opponentDisconnected (null | graceDeadline... done-ойыншыда graceDeadline жоқ — жай true/уақытсыз белгі: opponentDisconnected: opp.connected ? null : (opp.graceDeadline ?? true)); sub question → question+deadline; sub feedback → question + feedback {correctOption, yourAnswer, yourCorrect, nextAt}; sub done → сұрақсыз (күту-экран пішіні).

**handler.js:** onMessage 'round:answer' → 'q:answer' (msg.idx integer, optionIndex 0..3 тексерісі); handleInviteAccept-тан matchSeed аргументі өшеді. Басқасы (effect-runner, кезек, persist-буфер, invite-тер) ӨЗГЕРІССІЗ.

**Тест-матрица (~33 кейс, толық қайта жазу):** createMatch/countdown; ойыншыға бөлек рет (әр seed-те seq реті әртүрлі); countdown кезінде өшік ойыншы frozen q0; дұрыс/қате жауап (q:result payload, кэпті atMs, opponent:progress); тәуелсіз прогресс (A 3 сұрақ өтті, B қозғалмады — B күйі өзгеріссіз); қорғандар (қос жауап, ескі idx, жарамсыз opt, countdown кезінде, дедлайн+1600); grace-терезе жауабы atMs=15000 кэппен; timeout; ескі q-таймер feedback кезінде еленбейді; next → келесі сұрақ / done → match:waiting (persist ЖОҚ) / екеуі done → finishMatch (тәртіп persist,send,send,end); тең ұпай — жылдам жеңеді, толық тең — draw; disconnect тек ӨЗ таймерін қатырады (қарсылас әсер алмайды — оның таймері тізімде қалады); disconnect feedback кезінде; **done-ойыншы disconnect → grace ҚОЙЫЛМАЙДЫ, кейін қарсылас аяқтаса әділ нәтиже**; reconnect q/next remaining дұрыс + atMs офлайн уақытын қоспайды; ескі grace reconnect-тен кейін еленбейді; racing қарсылас grace бітті → forfeit (алда болса да); екеуі өшік → aborted persist-сіз; applyLeave (racing және done кезінде) → forfeit; snapshot әр sub-қа (question index-і ЛИКТЕЛМЕЙДІ, feedback пішіні, done пішіні, opponentProgress/Disconnected).

## Task 5 — Сервер: h2h endpoint

**Файл:** `server/src/routes/battles.js` (GET /:id-ден ЖОҒАРЫ орналастыру).
`GET /api/battles/h2h/:opponentId` (router requireApproved-та; isDbId тексерісі → 400):
```sql
SELECT COUNT(*) FILTER (WHERE winner_id = $1)::int AS wins,
       COUNT(*) FILTER (WHERE winner_id = $2)::int AS losses,
       COUNT(*) FILTER (WHERE winner_id IS NULL)::int AS draws
FROM battles
WHERE status = 'completed'
  AND ((challenger_id = $1 AND opponent_id = $2) OR (challenger_id = $2 AND opponent_id = $1))
```
$1 = req.student.id → `{wins, losses, draws}`. Route-тест жазылмайды (конвенция).

## Ескертулер (қабылданған шешімдер)

- Аяқтаған ('done') ойыншыға grace-forfeit ҚОЛДАНЫЛМАЙДЫ (қолданушы растады); саналы match:leave кез келген күйде forfeit болып қалады.
- Өшік ойыншыдан жауап қабылданбайды (жаңа сокет applyReconnect-тен кейін ғана хабар өткізеді — қатып қалған elapsed-логика қажет емес).
- atMs ROUND_MS-пен кэптеледі — durationMs енді тай-брейк ретінде тәуелсіз жүгірістерде салыстырылады.
- opponent:progress қарсыласқа әр жауаптан кейін ғана барады (спам жоқ, ~10 хабар/матч).
- Протокол rename alias-сыз — сервер рестарты in-memory матчтарды жояды, нұсқа-қайшылық терезесі жоқ.
