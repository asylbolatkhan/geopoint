# GeoVictorina Telegram Mini App — дизайн құжаты

**Күні:** 2026-07-22
**Күйі:** бекітілген (мұғаліммен бірге талқыланып мақұлданды)

## Мақсат

Қазіргі GeoVictorina сайтын (мұғалім сабақта қолданатын құрал) өзгертпей, оқушыларға арналған
Telegram Mini App жасау:

- Оқушылар бір-біріне **асинхронды батл** тастай алады
- **Жаттығу** (жалғыз ойын) режимі бар
- **Ай сайынғы рейтинг**: оқушы (сынып ішінде және мектеп бойынша) және сыныптар арасында
- Мұғалімге **админ панелі**: оқушыларды растау, рейтингті басқару, статистика

Аудитория: әзірге **бір мектеп**. Деректер құрылымы бірден көп мектепке дайын болады.

## Шешілген мәселелер (талқылау қорытындысы)

| Сұрақ | Шешім |
|---|---|
| Батл форматы | Алдымен асинхронды; real-time («Онлайн батл») кейін. Батырмасы қазірден тұрады, «Жақын арада 🔒» деп өшірулі |
| Тіркелу | Оқушы өзі тіркеледі (аты + сынып), мұғалім растайды |
| Ауқым | Бір мектеп, схема көп мектепке дайын |
| Рейтинг көзі | Батл + жаттығу, батл салмақтырақ |
| Админ | Оқушыларды растау, рейтинг басқару, статистика — бәрі мини-апп ішінде |

## Архитектура

```
Геоплатформа/
├── (қазіргі сайт — түбірде, функционалдық өзгеріссіз)
├── shared/          # елдер деректері + quizEngine (екі қосымшаға ортақ)
├── tma/             # Telegram Mini App — React + Vite + Tailwind + Telegram SDK
└── server/          # Node.js (Express) + PostgreSQL + grammY (бот)
```

- **Қазіргі сайт**: бір ғана өзгеріс — `src/data/` мен `quizEngine` `shared/`-ке көшеді,
  сайт импорттары жаңартылады. Сыртқы түрі мен мінез-құлқы өзгермейді; көшіруден кейін толық тексеріледі.
- **tma**: қазіргі дизайн стилінде, мобильге оңтайландырылған. Тілдер: kk / ru (қазіргідей).
- **server**: бір процесте API + Telegram бот (webhook) + tma статикалық файлдарын тарату.

### Деплой (Railway)

| Сервис | Мазмұны |
|---|---|
| geopoint-website (қазіргі) | Өзгеріссіз қалады |
| geo-tma-server (жаңа) | API + бот + tma статикасы |
| PostgreSQL (жаңа) | Railway Postgres плагині |

### Авторизация

- Кіру тек Telegram арқылы: мини-апп ашылғанда Telegram беретін `initData` әр API-сұраныспен
  жіберіледі, сервер оны бот токенімен (HMAC) тексереді. Пароль жоқ.
- Админ құқығы мұғалімнің Telegram ID-іне байланған (серверде сақталады, кейін басқа
  админ қосуға болады).

## Оқушы тәжірибесі

### Тіркелу

1. Оқушы ботты ашады → «Ойнау» → мини-апп
2. Аты-жөні, сынып (тізімнен), тіл (kk/ru)
3. «Өтінім жіберілді» экраны — расталғанша ойнай алмайды
4. Мұғалім растаған соң ботқа хабарлама келеді, қосымша ашылады

### Басты экран — 4 таб

- 🎮 **Ойнау** — жаттығу: құрлық, сұрақ түрлері, сұрақ саны, таймер (қазіргі solo сияқты)
- ⚔️ **Батлдар** — белсенді/өткен батлдар + «Батл тастау» + «Онлайн батл» (өшірулі, «Жақын арада 🔒»)
- 🏆 **Рейтинг** — сынып / мектеп / сыныптар жарысы; осы ай / барлық уақыт; өткен айлар мұрағаты
- 👤 **Профиль** — ұпайлар, жеңістер, дәлдік, тіл ауыстыру

### Асинхронды батл ағымы

1. Оқушы қарсылас таңдайды (өз сыныбы тізімі немесе мектеп бойынша іздеу) + параметрлер:
   құрлық, сұрақ саны (10/15/20), сұраққа уақыт (15 сек)
2. Сервер **бірдей сұрақтар базасын** жасайды, бірақ әр ойыншыға сұрақтар **өз кезегімен
   (араласқан ретпен)** беріледі, жауап нұсқаларының орналасуы да әр ойыншыда бөлек араласады —
   қатар отырып көшіру мүмкін емес. Тастаушы өз кезегін бірден ойнайды.
3. Қарсыласқа бот хабарлама жібереді: «X саған батл тастады! ⚔️» (батырма → мини-апп)
4. Қарсылас өзіне ыңғайлы уақытта ойнайды (48 сағат ішінде)
5. Нәтиже: әуелі дұрыс жауап саны, тең болса жалпы уақыты аз ойыншы жеңеді
6. Екеуіне де бот арқылы нәтиже хабарламасы жіберіледі

### Батл ережелері

- Клиентке дұрыс жауап алдын ала жіберілмейді — дұрыстықты сервер тексереді
- Батлды бастап шығып кетсе, жалғастыру жоқ: қалған сұрақтар қате саналады
  (жауап іздеп шығып кетуді болдырмау)
- Бір қарсыласқа күніне ең көп 3 батл (спамнан қорғау)
- 48 сағатта жауап берілмесе батл «күйеді» (төмендегі ұпай ережесін қара)
- Қарсылас батлды ашық түрде «Қабылдамау» батырмасымен қайтара алады — бұл күйген батлмен
  бірдей есептеледі (тастаушыға +10, қабылдамағанға −10), тек бірден

## Ұпай жүйесі

Барлық сандар серверде бір конфигурация файлында тұрады (өзгерту оңай).

| Оқиға | Ұпай |
|---|---|
| Батл жеңісі | +20 |
| Батл тең | +10 (екеуіне) |
| Батл жеңілісі | +4 |
| Батлдағы әр дұрыс жауап | +1 (екі жаққа) |
| Батл жауапсыз күйді (48 сағ) | Тастаушыға +10, елемегенге **−10** |
| Жаттығудағы әр дұрыс жауап | +1 (күніне жаттығудан ең көп 30 ұпай) |

Күйген батлда тастаушының дұрыс жауаптарына қосымша +1/жауап берілмейді (тек +10);
жаттығу лимитіне әсер етпейді.

## Рейтинг

- **Сынып рейтингі** — сынып ішіндегі оқушылар
- **Мектеп рейтингі** — барлық оқушылар
- **Сыныптар жарысы** — сынып ұпайларының қосындысы / оқушы саны (орташа)
- Кезеңдер: **осы ай** және **барлық уақыт**
- Ай аяқталғанда рейтинг мұрағатқа түседі (өткен айлардың 🥇🥈🥉 көруге болады);
  жаңа ай нөлден басталады. Рейтинг `points_events` журналынан ай кілті бойынша есептеледі —
  бөлек «нөлдеу» операциясы жоқ.

## Админ панелі («Басқару» табы, тек админге көрінеді)

1. **Өтінімдер** — жаңа тіркелгендер: қабылдау / қабылдамау, қабылдаған кезде сыныбын түзету.
   Жаңа өтінім түскенде мұғалімге бот хабарлама жібереді.
2. **Оқушылар** — расталғандар тізімі: сыныбын өзгерту, өшіру (ұпайлары рейтингтен алынады).
3. **Рейтинг басқару** — оқушының ұпай журналын көру, күдікті жазбаны жою
   (рейтинг автоматты қайта есептеледі).
4. **Статистика**:
   - Оқушы бойынша: ойын саны, дәлдік %, қай құрлықта қиналады
   - Сынып бойынша: ең жиі қателесетін елдер/астаналар
   - Белсенділік: соңғы 7 күнде кім ойнады/ойнамады

## Деректер қоры (PostgreSQL)

- `schools` — id, атауы (әзірге бір жазба)
- `classes` — id, school_id, атауы (мыс. «7Ә»)
- `students` — id, tg_user_id (unique), аты, class_id, status (pending/approved),
  role (student/admin), lang, created_at
- `battles` — id, challenger_id, opponent_id, config (JSON), questions (JSON, екеуіне ортақ база),
  challenger_result / opponent_result (JSON: жауаптар + уақыттар), status
  (awaiting_opponent/completed/expired/declined), winner_id (null = тең), created_at, expires_at
- `solo_games` — id, student_id, config (JSON), correct_count, total, duration, created_at
- `points_events` — id, student_id, amount, reason (battle_win/battle_draw/battle_loss/
  battle_correct/battle_expired_bonus/battle_expired_penalty/solo_correct), ref_id, month_key
  (мыс. «2026-07»), created_at

Рейтинг пен статистика — `points_events` + ойын кестелерінен агрегация. Жеке «ағымдағы ұпай»
бағаны жоқ: журнал жазбасы өшірілсе, барлық көрсеткіш өзінен-өзі түзеледі.

## Қателерді өңдеу

- Интернет үзілсе: жауаптар клиентте сақталып, қосылған соң қайта жіберіледі (retry)
- Батл мерзімін сервер сағат сайын тексеріп, күйген батлдардың ұпайын өзі жазады (cron/interval)
- Расталмаған (pending) оқушыға тіркелу-күйінен басқа барлық API жабық
- Әр сұраныста initData қолтаңбасы тексеріледі; жарамсыз болса 401
- Бір батлға нәтижені екі рет жіберу мүмкін емес (идемпотенттік тексеріс)

## Тестілеу

- **Автоматты тесттер (сервер):** ұпай есептеу, батл шешімі (жеңімпаз/тең/уақыт бойынша),
  айлық агрегация, күйген батл өңдеу, initData валидация
- **Қолмен:** Telegram тест-режимі + браузер; іске қосу алдындағы сценарий:
  тіркелу → растау → жаттығу → батл (екі аккаунт) → рейтинг → админ әрекеттері

## Іске қосу қадамдары

1. BotFather-де бот жасау (токен мұғалімде)
2. Код: shared бөліп алу → server → tma → админ
3. Railway: жаңа сервис + PostgreSQL, айнымалылар (BOT_TOKEN, DATABASE_URL, ADMIN_TG_ID)
4. Мұғалім кіріп сыныптарды енгізеді, оқушыларға бот сілтемесі таратылады

## Кейінге қалдырылған (осы нұсқаға кірмейді)

- Real-time «Онлайн батл» (батырмасы өшірулі күйде тұрады)
- Көп мектеп режимі (схема дайын, UI жоқ)
- Мұғалімнің тапсырма беру функциясы
- Қазіргі сайт пен мини-апп арасында ортақ аккаунт/синхрондау
